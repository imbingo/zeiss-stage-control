# V2.8.1：连接就绪、步骤入口与演示退出修复

针对实机反馈的四项问题：

1. 硬件库的“通信连接”不等于业务就绪，但 mark 模块此前没有衔接检查入口。进入 mark 标签时，现在会对仅通信连接执行一次只读就绪检查；界面另有“检查设备就绪”重试按钮。检查读取 Z，有 XY 时检查 XY 有限位置及空闲状态；不会重连、加载实验或清空实验 ID。未通过时保留未就绪状态，不以通道已连接冒充业务就绪。
2. “＋步骤”此前只切换到步骤库，必须再双击条目。现在直接弹出分类动作菜单；步骤库另有“添加所选步骤”按钮，保留双击方式。正式版只读时明确提示复制为新草稿。
3. 旧硬件单步对任何可能运动的调用都留下恢复锁，成功返回后也要求四项恢复确认。现在成功的 Z/XY 动作会只读检查目标位置和连续稳定读回；加载实验、AF、SNAP 和实验采集还检查对应实验/采集运行标志。确认完成才清除本次临时锁；超时、失败、缺少状态接口、停止请求和日志异常仍保留恢复锁，不重发动作。参数写入不会把已经就绪的设备降为仅通信状态。写入前的单项动作确认保留。
4. 顶部增加“退出离线演示”按钮；设备页的断开按钮在演示模式下也显示同名入口。退出后断开模拟连接，回到设备页，不自动连接或操作真实设备。当前任务执行中须先停止/等待完成。

旧版已经留下的未确认记录不能根据新版本自动认定为安全；这些历史记录仍需现场确认一次。正常完成且读回可验证的新操作不再反复触发四项恢复确认。

Z 默认完成容差为 0.5 µm，XY 为 1 µm；实验状态和轴位置验证不等于转盘锁定或图像质量判定。接口不能提供必要完成证据时，界面仍要求人工核实。

新增回归：7 项核心状态/完成验证测试和 5 项 Qt 操作入口测试；原恢复对话框测试改为注入真实的“完成状态无法验证”故障，继续检查四项确认和恢复日志。
